# Palette des personnages

Règle d'univers : dans ce monde sombre, les couleurs vives sont rares et sont la source de la vie ; seuls les immortels les portent. L'interface suit le Design System v3 ; les personnages ont cette palette.

## 1. Base sombre (tous)

| Couleur | Code |
|---|---|
| Noir du vide | `#0d0a07` |
| Brun d'ombre | `#2a2018` |
| Cendre | `#45403a` |

## 2. Couleurs des héros mortels (jamais reprises par un ennemi, sauf le bleu nuit des Hésiums en section 8)

| Héros | Couleur | Code |
|---|---|---|
| Maelor | Rouge vin profond | `#4a0f1b` |
| Maelor | Rouge vin | `#6e1626` |
| Corvin | Bleu nuit | `#141c2e` |
| Corvin | Flamme et sorts | `#8fb8e0` |

## 5. Or (héritage immortel seulement)

| Couleur | Code |
|---|---|
| Or ancien | `#c9a84c` |
| Or vif | `#f0c95a` |

Usage : sang et yeux de Maelor, lumière d'Elwen, Larme dorée. Aucun ennemi ne porte d'or, sauf les Tyrdrak (section 8).

## 6. Couleurs vives (immortels seulement, aujourd'hui Elwen seule ; exception des Tyrdrak en section 8)

| Couleur | Code | Usage |
|---|---|---|
| Rose foncé | `#a8325e` | Cheveux |
| Violet foncé | `#4b1d5c` | Pointes |
| Violet clair | `#9b6fd0` | Yeux |

## 7. Ennemis (terreux désaturés)

| Couleur | Code |
|---|---|
| Os gris | `#8f8a7c` |
| Rouille | `#6b3a22` |
| Fer | `#3d3f42` |
| Mousse | `#3e4632` |
| Fourrure et cuir | `#4a3a2c` |

- Une seule touche par ennemi, toujours sombre : braise sombre `#7a2a14` (yeux, braises). Elle tire vers le brun orangé pour ne pas se confondre avec le rouge vin de Maelor.
- Feu du dragon : braise sombre et noir, pas de feu vif.
- Les ennemis évitent les tons de peau des héros et le cendré clair de Maelor.

## 8. Exceptions : les Tyrdrak (Vahn) et les Hésiums

- Les Tyrdrak portent l'or (reflets des écailles, peau sous les écailles) et des couleurs vives (yeux rose violet), signe de leur lien avec les immortels.
- Les Hésiums portent le bleu nuit de Corvin `#141c2e` dans leurs longs cheveux : exception assumée, ils deviennent ses alliés (MAE-65). Décision du 28/10/2026, d'après les bases Gemini (MAE-26).
- La peau des Hésiums est bronzée (elle remplace le gris `#45403a`) ; sa valeur est fixée à la réduction (MAE-26) et reste à l'écart des peaux des héros.
- Aucun autre ennemi.
- Fiches : `docs/enemy-sheets.md`.

## Usage

- Ces couleurs sont données à Gemini dans chaque demande de base (fiches MAE-62).
- Elles peuvent bouger un peu à la réduction ; contrôle sur la planche dans MAE-26.
- Valeurs nouvelles du 28/10/2026 : brun d'ombre, cendre, bleu nuit de Corvin, les trois couleurs d'Elwen, les trois peaux des héros, le cendré clair de Maelor et toute la famille des ennemis (dont l'os gris `#8f8a7c`, qui remplace l'os `#b8ab92`).
